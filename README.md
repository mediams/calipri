# calipri prototype

Прототип desktop-приложения на Python для анализа параметров, сравнения с порогами и генерации цветного PDF-отчёта.

## Что умеет

- Выбор входного файла через диалог (`.csv`, `.xlsx`, `.xls`).
- Анализ значений относительно настраиваемых порогов (`min`/`max`).
- Цветной PDF c шапкой, оглавлением, таблицей и логотипом.
- Сохранение PDF в ту же директорию, где выбран исходный файл.
- Ограничение срока работы прототипа (по дате старта + количество дней).

## Быстрый старт (Windows Server 2016 x64)

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m app.main
```

## Версия прототипа

- Текущая версия приложения хранится в `app/version.py`.
- Эта версия выводится в заголовке окна и в PDF-отчёте (`Version: vX.Y.Z`).

## Формат входного файла

Обязательные столбцы:
- `parameter` — код параметра (например, `TEMP`)
- `value` — измеренное значение

Пример: `sample_data.csv`.

### Режим ET6 (CSV из измерительной системы)

- Если в CSV нет столбцов `parameter`/`value`, включается ET6-режим.
- Поддерживаются нестандартные CSV: автоопределение кодировки, разделителя и обработка «рваных» строк.
- Вывод формируется в читаемой матрице на одном листе A4 (landscape):
  - первая колонка `Name` (параметры),
  - остальные колонки осей (`11L`, `11R`, `12L`, `12R`...),
  - пустые значения остаются пустыми.
- Поддерживается как «широкий» CSV (когда оси уже в колонках), так и «длинный» формат (`Name/Achse/Seite/Wert`) с автоповоротом в матрицу.
- Для длинного ET6 формата автоматически строятся читабельные групповые строки (`Spurkranz`, `Raddurchm`, `Brems In`, `Brems Aus`, `Differenz`) и значения в ячейке объединяются при необходимости.
- Текущий фокус-режим: вывод по `Achse11`, `Achse12`, `Achse13`, `Achse14`, `Achse42`, `Achse41`, `Achse52` в колонки вида `11L`, `11R`, `12L`, `12R` и т.д.
- Значение `unmeasured` автоматически заменяется на `---`.
- Подсветка по `Dimension.Classification`:
  - `n.i.o` → красная ячейка;
  - `Achtung` → жёлтая ячейка.

## Где менять настройки

Файл `config/defaults.json`:
- `thresholds` — пороги, отображаемые имена, единицы;
- `pdf.logo` — путь до логотипа;
- `license.start_date` и `license.valid_days` — окно срока работы.

## Примечание по логотипу

- Используйте корректный файл изображения (`.png`, `.jpg`, `.jpeg`).
- По умолчанию `pdf.logo` пустой — отчёт формируется без логотипа.
- Если файл логотипа повреждён или формат не поддерживается, отчёт всё равно сформируется, а логотип будет пропущен с уведомлением в PDF.
